# ✅ Patterns That Commonly Fall Under Arrays

## 🔁 Two Pointers
Used when working from both ends or merging logic.
Examples:
* Pair sum 
* Remove duplicates 
* Reverse array 
* Container with most water 

## 🪟 Sliding Window
Used for contiguous subarrays / substrings.
Types:
* Fixed window 
* Variable window 
Examples:
* Maximum sum subarray of size K 
* Longest subarray with condition 
* Minimum window substring 

## ➕ Prefix Sum
Used for range queries and subarray calculations.
Examples:
* Subarray sum equals K 
* Range sum queries 
* Product of array except self 

## 🔍 Binary Search on Array
Used when array is sorted OR answer space is monotonic.
Examples:
* Search element 
* First/last occurrence 
* Rotated sorted array 
* Peak element 

## 🔄 Cyclic Sort (Index-Based Placement)
Used when numbers are in range 1..N.
Examples:
* Missing number 
* Find duplicate 
* First missing positive 

## 📚 Hashing (Frequency Map)
Used for counting and fast lookup.
Examples:
* Two sum 
* Majority element 
* Longest consecutive sequence 

## 📊 Sorting + Greedy
Sort first, then make optimal choices.
Examples:
* Minimum number of arrows 
* Assign cookies 
* Boats to save people 

## 🧮 Kadane's Algorithm
Maximum subarray type problems.
Examples:
* Maximum subarray sum 
* Maximum product subarray 

## 🧱 Monotonic Stack (on arrays)
Used for next greater/smaller element.
Examples:
* Next greater element 
* Histogram largest rectangle 
* Daily temperatures 

## 🧠 Divide & Conquer
Split array and combine result.
Examples:
* Merge sort 
* Maximum subarray (divide approach)

## 🧠 Big Insight
Array is not a pattern itself.  Array is a data structure.
Patterns are the ways you operate on arrays.

## 🏁 Final Answer
👉 Arrays mainly use Two Pointers, Sliding Window, Prefix Sum, Binary Search, Cyclic Sort, Hashing, Greedy, Kadane's Algorithm, and Monotonic Stack patterns.
